# Режимы (modes) в Kilo Code

В Kilo Code «режим» — это специализированная роль ассистента с разным набором прав и
фокусом. Переключатель — в панели Kilo, через `/agents` в чате или `Cmd+.` /
`Ctrl+.`. Источник: <https://kilo.ai/docs/code-with-ai/agents/using-agents>.

Встроенных режимов пять: **Code**, **Ask**, **Plan**, **Debug**, **Orchestrator**.
Свои режимы делаются через `.kilo/agents/<имя>.md` (1.4.1–1.4.2).

## По одной строке на каждый тип агента

- **Code** — квалифицированный инженер: полный доступ к инструментам, пишет код и запускает команды.
- **Ask** — технический ассистент: только чтение и read-only bash, отвечает на вопросы без правки кода.
- **Plan** — архитектор: read-only плюс редактирование только планов в `.kilo/plans/`.
- **Debug** — диагност: полный доступ к инструментам, методично расследует и чинит баги.
- **Orchestrator** — координатор (устарел): ограниченный набор, делегирует задачи другим режимам.
